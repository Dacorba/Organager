# Organager
 
Organager is a personal productivity and task management application designed to simplify planning, organization and workflow management.
 
## Features
 
- Task creation and organization
- Priority management
- Workflow tracking
- User-friendly mobile interface
 
## Technologies
 
- TypeScript
- React Native
- Expo
 
## Status
 
Beta testing.
 
The application is currently in active use and undergoing continuous refinement based on day-to-day usage, feedback and feature validation.
